# UNIDAD-2-BASE-DE-DATOS-EJERCICIO-9
Se pide diseñar un Modelo Entidad-Relación (MER) para una plataforma educativa, que permita administrar los instructores, cursos, módulos, lecciones, estudiantes, inscripciones y evaluaciones.

El modelo debe contemplar:

- Instructores: registrar su ID, nombre, biografía, especialidad y datos de contacto. Cada instructor puede crear e impartir varios cursos.
- Cursos: almacenar su código, título, descripción, nivel de dificultad y precio. Cada curso debe contener uno o varios módulos ordenados secuencialmente.
- Módulos: organizar el contenido de cada curso y contener múltiples lecciones.
- Lecciones: registrar título, tipo de contenido (video, lectura o recurso descargable), duración estimada y enlace digital.
- Estudiantes: registrar a los alumnos y sus inscripciones en distintos cursos, incluyendo la fecha de alta, el porcentaje de avance y el estado de finalización.
- Evaluaciones: cada curso incluye cuestionarios o exámenes compuestos por preguntas de opción múltiple.
- Intentos de evaluación: registrar cada intento realizado por un estudiante, con su fecha, calificación y estado (Aprobado o Desaprobado).

Finalmente, se deben identificar las entidades, sus atributos, las relaciones y las cardinalidades, respetando las reglas de negocio, como la inscripción de estudiantes en múltiples cursos y la organización secuencial de los módulos.
